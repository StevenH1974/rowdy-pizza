# The Rowdy Pizza

A food blog built from scratch in raw HTML/CSS/JS, currently in active development as part of my coding portfolio.

## Current Status
This project is a work in progress. Right now I'm focused on writing out each blog post in clean, semantic HTML before moving into CSS design. That means:

- Pages are currently unstyled — CSS is the next phase
- Some internal links point to posts that haven't been built yet
- Images are placeholders for now; photography comes after the HTML/CSS phase

## About
The Rowdy Pizza is a food blog covering pizza dough science, recipes, and technique, co-owned with Ricky. It'll eventually grow into an e-commerce site.

## Tech Stack
- HTML, CSS, JavaScript (no framework — hand-coded)
- Hosted on Netlify (planned)
- Version controlled with Git/GitHub
